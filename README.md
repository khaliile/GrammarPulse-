# ⚡ GrammarPulse — English Grammar Studio

An interactive, visual learning application built to make mastering English verb tenses intuitive, practical, and engaging.

GrammarPulse removes the confusion of dry grammar textbooks by combining **interactive timelines**, **formula builders**, **real-world use cases**, **mistake traps**, **gamified practice exams**, and **native voice pronunciation**.

---

## 🎯 How It Works for Learners (Simple Guide)

GrammarPulse is organized around an easy-to-follow **3-step learning journey**:

1. **Understand the Big Picture**: Select any tense from the dropdown (Past Simple, Present Continuous, Future Perfect, etc.) to see its visual timeline and discover when native speakers actually use it.
2. **Master the Rules & Traps**: Learn positive (`+`), negative (`-`), and question (`?`) structures, explore secret spelling patterns, and review common mistakes before you make them.
3. **Practice, Listen & Score**: Complete interactive fill-in-the-blank drills, take timed exams to earn XP and streaks, and listen to natural native voice pronunciation.

---

## 🎛️ The 11 Interactive Learning Stations

Every English tense includes 11 dedicated stations:

| Station | What You Can Do |
| :--- | :--- |
| **🗺️ 1. Overview** | A visual mental timeline showing exactly *when* an action happens (past, present, or future) and why. |
| **📐 2. Formulas** | Click-and-explore blueprints for **Affirmative (+)**, **Negative (-)**, and **Question (?)** forms across all subject pronouns (*I, You, He, She, We, They*). |
| **💼 3. Real-Life Use Cases** | Practical daily scenarios (e.g., job interviews, daily routines, storytelling, making promises). |
| **🔬 4. Spelling Lab** | Clear rules for tricky verb changes (`-ed`, `-ing`, `-s/-es`, doubled consonants) without headaches. |
| **⏱️ 5. Frequency Signals** | "Clue words" (*always, yesterday, right now, by next year*) that immediately reveal the correct tense. |
| **⚠️ 6. Common Traps** | Highlights the #1 mistakes English learners make and shows how to avoid them. |
| **📋 7. Quick Resume** | A clean, 2-minute visual cheat sheet for fast review before tests. |
| **✍️ 8. Interactive Exercises** | Fill-in-the-blank and sentence-building drills with instant scoring and explanation. |
| **🏆 9. Mastery Exam** | A timed quiz with scoring, XP rewards, and streak tracking to test your knowledge. |
| **🛣️ 10. Course Workflow** | A step-by-step roadmap guiding learners from foundational tenses to advanced forms. |
| **🎧 11. Audio Pronunciation** | Listen to sentences spoken aloud by native voices with adjustable speed (normal or slow). |

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your computer.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/khaliile/GrammarPulse-.git
   cd GrammarPulse-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

### Running the Application

* **Option A: Run in the Web Browser (Fastest)**
  ```bash
  npm run dev
  ```
  Open your browser and navigate to `http://localhost:5173`.

* **Option B: Run as a Desktop App**
  ```bash
  npm run desktop
  ```
